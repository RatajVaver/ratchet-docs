# RIFT <Badge type="tip" text="Enhanced" /> <Badge type="danger" text="Work in Progress" />
RIFT is a Roleplay Framework, currently in development and not yet published.

This framework will consist of three parts: Workshop mod, built-in Ratchet compatibility layer, and an open-source Lua plugin.

## `Redirect` <Badge type="info" text="function" />
Redirects a player to another server.

Syntax:
```lua
bool R3.Redirect( Character player, string address [, string title = "" ] )
```
